# Historie

Archiv der früheren `Fortschritt.md`, nach Monaten geteilt (11.11.2026, Inhalt unverändert):

| Datei | Inhalt |
|---|---|
| `2026-09.md` | Ursprünglicher Stand (Kernlogik, Desktop, Web) bis Ende September 2026, Versionen bis 1.0.38 |
| `2026-10.md` | Oktober 2026: Versionen 1.0.39 bis 1.0.51, Sicherheits- und Codeprüfungen, UX-Test, Desktop-Prüfung, Verbesserungen |
| `Fortschritt.md` (Wurzel) | laufender Monat (ab November 2026) |

Nur zum Nachschlagen: den aktuellen Stand liefern `OFFEN.md`, `Architektur.md` und
`entscheidungen/`. Ein früherer Beschluss lässt sich mit `git grep -i "Stichwort" -- historie`
finden. Am Monatsende wird der laufende Monat hierher verschoben (neue Datei `JJJJ-MM.md`).

Die Berichte der einzelnen Prüfungen (Sicherheit, UX-Test, Desktop-Prüfung, QS) liegen in
`berichte/`.
