# Symbole der Oberfläche

Die SVG-Dateien in diesem Ordner sind unveränderte Outline-Symbole aus **Tabler Icons**:

- Quelle: <https://tabler.io/icons>
- Paket: `@tabler/icons` in Version 3.49.0 (Ordner `icons/outline/`)
- Lizenz: MIT, Text in `LICENSE-Tabler.txt` (Copyright (c) 2020-2026 Paweł Kuna)

Das Programm färbt sie erst beim Zeichnen ein (`currentColor` wird ersetzt, siehe
`desktop_gemeinsam.symbol`). Welche Symbole die Oberfläche verwendet, steht in
`desktop_gemeinsam.SYMBOL_NAMEN`; der Selbsttest der gebauten Fassung prüft sie.
Eingeführt mit dem Erscheinungsbild „Beagle“ (Marco 01.11.2026).
