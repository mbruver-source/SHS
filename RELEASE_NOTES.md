## Was ist neu in 1.0.44

Diese Version sorgt dafür, dass künftige Updates ein noch laufendes Programm sicher
erkennen. Deine Termine bleiben beim Update erhalten – einfach die neue Version über die alte
installieren.

**Update über das laufende Programm**
- Bisher konnte das Setup ein noch geöffnetes Programm übersehen, z. B. wenn ein
  Virenscanner die Programmdatei gleichzeitig prüfte. Dann kam beim Installieren „Fehler
  beim Ersetzen einer vorhandenen Datei … Zugriff verweigert“.
- Ab dieser Version meldet sich das Programm beim Start so an, dass das Setup es sicher
  erkennt. Läuft es beim nächsten Update noch, bittet das Setup gleich zu Beginn, es zu
  schließen. Beim Schließen werden offene Ergebnisse wie gewohnt gespeichert. Auch die
  Deinstallation erkennt ein laufendes Programm.
- Das wirkt ab dem Update **von** 1.0.44 auf eine spätere Version. **Für dieses Update
  bitte das Programm vorher selbst schließen.** Kommt trotzdem „Zugriff verweigert“: Programm
  schließen, dann „Nochmals versuchen“ klicken.

**Handbuch**
- Kapitel 2 „Installation und Updates“: Hinweis, das Programm vor dem Update zu schließen,
  und was bei „Zugriff verweigert“ zu tun ist. Bilder auf 1.0.44 erneuert.

Alles Weitere aus 1.0.43 (Demoprüfung läuft von allein weiter, Secrets für die
Web-Version) gilt unverändert.
